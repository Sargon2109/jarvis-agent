Jarvis Agent — Project Summary

Jarvis Agent is an experimental Python project for building a multi-agent
orchestration system on top of Anthropic's Claude Agent SDK. It has two
dependencies: `claude-agent-sdk`, which provides the core agent framework,
and `python-dotenv`, used to load environment variables such as API keys.

The project offers two entry points. `agent.py` runs a single standalone
Claude agent equipped with Read, Glob, Grep, Write, and Edit tools, but is
restricted to writing or editing files only within a sandboxed `scratch/`
directory. `main.py` is the more advanced entry point, launching an
"orchestrator" agent (configured in `config/options.py`, using the
claude-sonnet-5 model) whose sole tool is `Task`. Rather than performing
work itself, the orchestrator delegates subtasks to specialized subagents:
a "researcher" (read-only tools: Read/Glob/Grep) and a "writer" (handles
content creation), coordinating them to complete complex requests while
keeping file output confined to the scratch folder.
